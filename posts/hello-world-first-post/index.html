写在博客开通的第一天

折腾了三个晚上，这个小站终于上线了。聊聊我为什么想写博客，以及 rnadow.top 之后想做成什么样子。

现在是凌晨一点四十七，DNS 刚刚生效，浏览器里敲下 rnadow.top、看到页面加载出来的那一刻，三个晚上熬得值了。第一篇就不写技术干货了，留几段碎碎念给未来的自己。

为什么想写博客

三个契机。

一是笔记太散了。备忘录、收藏夹、语雀、手机里各种 App，记的时候很勤快，回头找的时候从来找不到。想有一个自己的、结构可控的地方把它们沉淀下来。

二是发现很多坑一年会踩两遍。上一次解决某个奇怪 bug 的过程明明记得清清楚楚，半年后再遇到，连关键词都想不起来。写下来的东西，至少对未来 Venice 嗯不，对未来 rnadow 有用。

三是看了几年阮一峰老师的科技爱好者周刊，越来越觉得「持续输出」这件事本身就挺酷的。不指望流量，先指望坚持。

为什么是手写 HTML

选型纠结了整整两个晚上：Hexo、Hugo、Typecho、Ghost，论坛里的对比帖看了几十篇，最后决定——就手写 HTML + CSS + JS。原因很简单：我想要一个完全属于自己的、每一行都看得懂的小站。没有模板语法、没有构建报错，改一行就能看到一行。

当然我知道文章多了以后手写不可持续，到时候再上静态生成器也不迟，目录结构和 URL 规则已经按那个方向设计了。有时候「先跑起来」比「先选对」更重要。

rnadow 是什么

常被问到的名字问题：rnadow 是当年想注册 random 相关 ID 时手滑打错的产物，将错就错用了很多年，反而成了独一份的标识——全网搜 rnadow，基本只有我。注册 rnadow.top 的那天还特意查了一圈，谢天谢地没人抢。

小站规划

  • 每月至少一篇，先从踩坑记录写起；
  • 方向：Web 开发、自托管、效率工具，偶尔写写生活；
  • 不放广告，不接统计，最多留一个不记名的访问计数；
  • 保持 RSS 全文输出，订阅即阅读，不搞「点击查看原文」。

最后

如果你也是刚巧搜到这里的陌生人，欢迎常来；如果是我认识的你——好了，别催更新了，第一篇这不就来了。

写下来，是对生活最大的抗遗忘。
