# 卡面工坊 · `cards/custom.html`

> 纯前端、零依赖的 **ISO 7810 ID-1** 标准卡面生成器，配合 **AirCard** 把自制卡面写进 Apple 钱包。
> 在线使用：<https://rnadow.github.io/cards/custom.html> ｜ 镜像：<https://www.rnadow.top/cards/custom.html>

上传照片或挑选高级质感底色，叠加 Logo / 芯片素材，配合参考图精准对位，支持智能去底色与外描边，
最后点对点导出 **1536 × 969** 超清 PNG。所有图片只在浏览器内存里处理，**不会离开你的设备**。

---

## ✨ 功能

### 卡面底图
- 拖拽或点击上传（JPG / PNG / WebP / SVG），自动**等比缩放并居中**填满卡面，超出部分裁掉，始终锁定 1.586 : 1。
- 画布上直接拖动平移、滚轮缩放底图。
- 「精细裁剪」：弹出裁剪框，拖动选区或 8 个手柄调整构图，比例锁定，可反复叠加裁剪。

### 质感底色
- 6 套预设：曜石黑金 / 极光流彩 / 落日熔金 / 香槟贵金 / 午夜幽蓝 / 深空钛灰。
- 也可用取色器自定义纯色底；底图未覆盖之处、以及半透明 Logo 的衬底都会显示该颜色。

### 对位参考图
- 用于对齐芯片、银行 Logo、卡号位置；透明度可调，叠在底图之上、Logo 之下。
- 参考图**只用于预览排版，绝不会出现在导出的 PNG 里**。

### Logo / 图章图层
- 一次可选多个文件，画布上拖动摆放、滚轮缩放、`Shift` + 滚轮旋转、方向键微调（`Shift` 加速）、`Delete` 删除。
- 图层管理器：显示 / 隐藏、上移 / 下移、复制、删除，点击即选中。
- **智能去白色底**：容差可调，带 48 级过渡带，保留抗锯齿边缘不出现白边。
- **轮廓外描边**：宽度与颜色可调，可开启「自动对比色」，按 Logo 明暗自动选黑 / 白描边。

### 导出
- 一键导出 **1536 × 969 PNG**（24 位带 Alpha），按 3.18 mm 物理圆角裁切，四角透明。
- 导出内容 = 你在预览里看到的一切，**不含参考图与选中框**，点对点无重采样损失。

其余细节：深色 / 浅色主题、条款与免责声明弹窗、响应式布局（窄屏自动单列）。

## 📐 规格

| 项目 | 值 |
| --- | --- |
| 卡面标准 | ISO 7810 ID-1，85.60 × 53.98 mm |
| 宽高比 | 1.586 : 1 |
| 导出尺寸 | 1536 × 969 px |
| 圆角 | 3.18 mm ≈ 57 px（`3.18 × 1536 / 85.60`） |
| 输出格式 | PNG（24 位 + Alpha，圆角外透明） |
| 文件命名 | `card-face-1536x969-<时间戳>.png` |
| 依赖 | 无。单个 HTML 文件，无构建、无 CDN、无外链字体 |

## 🚀 快速开始

1. 打开 <https://rnadow.github.io/cards/custom.html>；
2. 「卡面底图」上传照片，或直接点一套质感预设；
3. 需要对齐位置时上传「对位参考图」，调好透明度；
4. 「Logo 与图章」上传素材，在画布上摆好，按需开启去底色与描边；
5. 点右上角「导出超清 PNG」，浏览器直接下载原画。

本地预览（`file://` 下可用，但建议起个静态服务器）：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080/cards/custom.html
```

## 📲 配合 AirCard 写入钱包

**[AirCard](https://aircardios.github.io/)** 是一个免越狱修改 Apple 钱包卡面、锁屏按键与 PosterBoard 壁纸的 iOS 工具。
本页面负责产出**合格尺寸的卡面原画**，AirCard 负责把它**写进系统钱包**，两者配合即完成从设计到生效的闭环。

| 入口 | 地址 |
| --- | --- |
| AirCard 官网 / 中文文档 | <https://aircardios.github.io/> |
| 本机构建（iOS 26.4 支持，MIT） | <https://github.com/rnadow/aircard> |
| 项目主页 | <https://rnadow.github.io/aircard/> |
| Windows 构建记录 | <https://rnadow.top/posts/aircard-ios-26-4-windows-build/> |
| 上游项目 | <https://github.com/Mak5er/AirCard-iOS> |
| 底层通信库 AirLift | <https://github.com/0xjohnnydev/airlift> |

操作步骤：

1. 在本工坊排版满意后，点「导出超清 PNG」，得到 1536 × 969 原画；
2. 把 PNG 传到 iPhone（AirDrop、文件 App、局域网共享均可）；
3. 打开 AirCard，在已配对的设备卡片列表里选中要换卡面的银行卡 / 交通卡；
4. 点「选择自定义卡面图片」，导入刚才那张 PNG；
5. 点「一键写入并注销生效（Respring）」，回到钱包即可看到新卡面。

> 写入的是本机 Wallet 资源，请先确认设备已按 AirCard 文档完成配对；替换前建议保留原始素材以便回滚。
> 本项目与 AirCard 官方**没有隶属或背书关系**，只是「出图 → 写入」的工具链搭档。

AirCard 的边界（摘自其项目主页，写入前请务必了解）：

- **会改**：设备上的本地视觉缓存（Wallet 卡面、锁屏按键、PosterBoard 壁纸等资源）。
- **不会改**：支付凭据、余额、发卡行记录与 Secure Element，不触碰任何交易数据。
- **建议**：先跑一遍安全兼容性探针，再用一张卡 + 一张可替换图片试水，确认无误后批量替换。
- **限制**：实验版本，不保证适配所有机型与系统构建。本工坊只负责产出 PNG，写入行为与风险由 AirCard 及使用者承担。

## 🧩 实现要点

- **设计空间 = 导出空间**：`<canvas>` 背板固定 `1536 × 969`，所见即所得，导出走独立离屏画布避免界面元素混入。
- **合成顺序**：质感底色 → 底图 → 参考图（仅预览）→ Logo 图层 → 圆角裁切 → 选中框（仅预览）。
- **去底色**：按 `min(r, g, b)` 亮度阈值判定背景，`阈值 ~ 阈值-48` 之间做 alpha 渐变过渡，避免锯齿白边。
- **描边**：把去底后的 alpha 剪影染色，沿圆周多步膨胀后再压回原图，得到均匀外描边（宽度随图层缩放同步）。
- **裁剪变换**：裁剪框在归一化坐标下天然等比（`w ≡ h`），应用时令 `f = 1536 / 选区宽`，
  `zoom *= f`、`offset = f × (当前中心 − 选区左上角) − 画布中心`，因此可无损反复叠加裁剪。
- **可访问性**：全部交互同时提供滑杆 / 按钮入口，键盘方向键与 `Delete` 可直接操作选中图层。

自测记录（无头 Chrome 端到端断言，数值为导出 PNG 的实测像素）：

| 用例 | 预期 | 实测 |
| --- | --- | --- |
| 渐变底图在 x=768 处的红通道 | 100 | 100 ✓ |
| 参考图仅预览 | 预览混色、导出纯底色 | 预览 `[73,79,37]` / 导出 `[100,0,0]` ✓ |
| 裁剪（右下角手柄拖到中心） | 56 | 56 ✓ |
| 二次裁剪叠加（左上角手柄） | 78 | 77（取整误差）✓ |
| 导出产物 | 1536×969、四角 Alpha=0 | 通过 ✓ |
